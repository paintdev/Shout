# Shout
My attempt on making something similar to Wispr Flow

**If you don't have a numpad change the hotkey in the code!**

## Installation
**Python 3.9.6 is recommended**

Run Git clone

```bash
git clone https://github.com/paintdev/Shout.git
```

Install requirements

```bash
pip install -r requirements.txt
```

Run Shout

```bash
python main.py
```
